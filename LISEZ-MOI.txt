JUSTEAU SAV — VERSION 6

NOUVEAUTÉS
- Menu Mécanicien : Gaetan, Michael, Jean Michel R., Jocelyn, Stéphane, Jean Michel et Laurent.
- Option « Autre… » : ajout d’un nouveau mécanicien directement depuis l’application. Le nom est mémorisé et apparaît ensuite automatiquement dans la liste.
- Récap mensuel amélioré : total heures, total pièces facturées HT, main-d’œuvre HT et total HT à facturer calculés automatiquement.
- Le taux horaire est mémorisé séparément pour chaque société après saisie.
- Champ e-mail comptabilité mémorisé.
- Bouton « Envoyer par mail » : ouvre la messagerie avec le récapitulatif complet et tous les totaux déjà calculés.
- Bouton « Partager le récap » pour iPhone/iPad/Android.
- Toutes les fonctions de la Version 5 sont conservées.

MISE À JOUR
1. Faites d’abord une sauvegarde depuis le menu ⋯ > Exporter les données.
2. Décompressez Justeau_SAV_Version_6.zip.
3. GitHub > Code > Add file > Upload files.
4. Envoyez index.html, app.js, styles.css, manifest.webmanifest, service-worker.js, icon-192.png et icon-512.png.
5. Commit changes.
6. Attendez environ 2 minutes.
7. Fermez complètement l’application puis rouvrez-la. Si nécessaire, ouvrez une fois l’adresse avec ?v=6.

IMPORTANT
Les réparations existantes sont conservées sur le même appareil. Les mécaniciens ajoutés via « Autre… », les taux horaires et l’adresse e-mail comptabilité sont mémorisés localement sur l’appareil.
